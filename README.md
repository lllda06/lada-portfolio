# ⚙️ Installation


Clone repository:

```bash
git clone https://github.com/lllda06/lada-portfolio.git
```


Navigate:

```bash
cd lada-portfolio
```


Install dependencies:

```bash
npm install
```


Run development server:

```bash
npm run dev
```


Open:

```
http://localhost:3000
```
